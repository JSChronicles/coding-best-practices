# Agent Instructions

This repository is the canonical source for reusable coding best-practices skills.

- Keep each skill under `skills/<skill-name>/` with its required `SKILL.md` and only the references, scripts, or assets it actually needs.
- Keep skill instructions provider-neutral. Use terms such as "the agent" or "the model" unless behavior genuinely applies to one product.
- Do not duplicate skill content under product-specific plugin directories. Product manifests should expose the canonical `skills/` directory.
- Preserve automatic skill discovery unless a skill is explicitly intended for manual invocation only.
- When creating or substantially editing a skill, use the available skill-creator guidance and validate the changed skill.
- Keep root plugin and marketplace metadata synchronized when the package version or description changes.
